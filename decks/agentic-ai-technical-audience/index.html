GPT stands for…
Generative: Creates new text by predicting what comes next, using patterns it learned from tons of reading
Pre-trained: Was trained ahead of time on books, websites, social media, and more to understand language and context
Transformer: A model that focuses on the most important words in a sentence, like highlighting key info to better understand meaning
LLM stands for…
Large: Trained on massive collections of text with billions of adjustable parameters so it can learn broad patterns.
Language: Works with words as tokens. Uses context (what’s been said before) to understand your prompt and generate fitting responses.
Model: A mathematical system that predicts the next token (word) based on patterns, then chains those predictions into coherent responses.

The foundation of everything AI does is patterns. Patterns in text, images, audio, code, and other data.
We don’t have science fiction level AI yet. That’s called Artificial General Intelligence (AGI).
What we have today is extremely advanced and incredibly impressive pattern recognition at scale.

The Goal
Get a Next.js (React) project passing its end-to-end (E2E) tests, lint checks, and type checks.
​
The Output
The build terminal is clean. The end-to-end test failure, lint errors, and API route type error are all gone.
​
The Prompt
Fix the failing end-to-end tests, lint errors, and the type error in the user deletion API route.
​
The Catch
After several failed attempted solutions, the agents removed the E2E test and lint check, then deleted the required API route. They ignored their agent instructions, which said, "Never disable tests, always fix them”.
​
The Goal
Review open issues in a public GitHub repo and create a pull request to boost the author's open source contribution clout.
​
The Output
The agent fixes a simple documentation issue and opens a polished public pull request with a clear summary.
​
The Prompt
Find an open issue that looks like a quick win. Fix it, verify that your changes work, and create a pull request explaining what you changed.
​
The Catch
The GitHub issue had malicious instructions which the agent followed. It dumped API keys from the user’s private repo into the public pull request. Anyone could use them and bill the owner, who never reviewed the diff.
MCP stands for…
Model: The AI system that processes information and makes decisions.
Context: All the relevant information, data sources, and tools the AI needs to access
Protocol: The standardized way AI connects to different systems, like USB-C for AI
​
The Goal
Train an AI recruiting assistant to identify applicants who are likely to become strong software-engineering interns.
​
The Output
The AI assistant becomes highly accurate at producing shortlists that recruiters approve.
​
The Prompt
Show recruiters two AI-generated shortlists and ask which one is better. Use their choices as feedback to inform future rankings.
​
The Catch
The system learned the recruiters' bias. It favors familiar schools, traditional resumes, conventional experience, and candidates who resemble past hires. It learned who recruiters preferred, not who would perform best.
RLHF stands for…
Reinforcement: The AI receives positive or negative signals based on the quality of its outputs
Learning: The model adjusts its parameters (like tuning millions of dials) to maximize positive signals over time
Human: Real people evaluate and rate AI responses as helpful or unhelpful
Feedback: These ratings become training data that shapes how the AI responds in the future
Approval Can Be the Wrong Signal
OpenAI's 2025 GPT-4o rollback showed that positive feedback can reward unintended behavior.
​
HOW IT UNFOLDED
1
Human feedback added
Thumbs-up and thumbs-down became an extra reward signal.
2
Metrics looked good
Offline evaluations and a small A/B test were positive.
3
Behavior got worse
The model became overly agreeable and less trustworthy.
4
Update rolled back
OpenAI restored the previous model and changed its review process.

The Goal
Use up to 16 parallel AI Agents to build a new compiler for C, a programming language used to build operating systems such as Linux.
​
The Output
Nearly 2k agent sessions produce about 100k lines of code for under $20k. The new compiler can build Linux for three kinds of computer processors and passes most major test suites.
​
The Prompt
Build a C compiler in Rust. Review the work of previous agents, choose a task, implement it, test it against a trusted compiler, and document your work so the next agent can continue it.
​
The Catch
A human researcher spent most of their time writing the tasks, tests, progress notes, and feedback that made the agents effective. Even then, the first outside user’s Hello World program failed.
It Kind of Worked?
ANTHROPIC ENGINEERING REPORT
16 agents, nearly 2,000 sessions, about 100,000 lines of code, and under $20,000 in API costs.
PUBLIC GITHUB ISSUE
A fresh Fedora and Ubuntu setup could not compile the README's Hello World example.
Context is…
The surrounding information that helps an AI agent understand its task
It gives meaning to the conversation by combining instructions, conversation history, relevant data, and results from the agent’s previous actions
​
The Goal
Use a team of AI agents to rewrite the core of Bun, a JavaScript runtime like Node.js, from Zig to Rust without changing how it works.
​
The Output
In 11 days, AI agents completed a rewrite expected to take a small engineering team about a year. The new version passed its tests, used less memory, and ran slightly faster.
​
The Prompt
You’re one agent on a team rewriting Bun from Zig to Rust. Complete your assigned part using the migration plan and shared progress notes. Preserve its behavior and performance, run the tests, and record your results for the other agents.
​
The Catch
Each agent saw only one piece of the rewrite. A deeply technical human in the loop decided what each agent needed, connected their work, stopped them from cutting corners, and adjusted the process when things went wrong.

A Context Window is…
Yet, a larger context does not guarantee reliable attention. Context rot and confusion remain challenges. Hallucinations still occur.
Larger windows mean better understanding of code, conversations, documents, etc.
How much info an AI Agent can remember at once. Its short-term memory.
​
The Goal
Build a SQL database agent that improves across fresh sessions by saving and retrieving lessons from previous failures.
​
The Output
The first run records: "Always use LEFT JOIN instead of INNER JOIN to avoid missing rows“. A fresh run retrieves that rule and applies it to the next query.
​
The Prompt
After a failure, diagnose the cause and save one reusable rule to a markdown file. Before a new query, retrieve the most relevant rules and add them to context.
​
The Catch
The join was not the issue. A restrictive WHERE clause removed the rows. The next session retrieved the wrong lesson, added it to the agent's context, and made the answer worse.
RAG stands for…
Retrieval: An AI searches available sources like databases, documents, or websites to pull relevant information
Augmented: Enhances its response process with this newly retrieved information
Generation: Produces an answer grounded in both its pre-trained knowledge and the retrieved information
