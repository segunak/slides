Generative AI Is Not Just Hype
Source: Microsoft Research
GPT stands for…
Generative: Creates new text by predicting what comes next, using patterns it learned from tons of reading
Pre-trained: Was trained ahead of time on books, websites, social media, and more to understand language and context
Transformer: A model that focuses on the most important words in a sentence, like highlighting key info to better understand meaning
LLM stands for…
Large: Trained on massive collections of text with billions of adjustable parameters so it can learn broad patterns.
Language: Works with words as tokens. Uses context (what’s been said before) to understand your prompt and generate fitting responses.
Model: A mathematical system that predicts the next token (word) based on patterns, then chains those predictions into coherent responses.

Agentic AI
​
​
Autonomy: Take goal-directed actions with minimal human oversight.
​
Reasoning: Provide contextual decision-making and make judgment calls and tradeoffs.
​
Adaptable Planning: Dynamically adjust plans based on changing conditions to complete processes.
​
Context Understanding: Comprehend and follow natural language and other modalities.
​
Action Enabled: Empowered to act via access to web services to deliver specific skills.

Some Final Thoughts
We’ve learned the concepts, now let’s explore some resources for further exploration.
•You built an AI agent today by writing English and picking tools.
•That’s a growing phenomena called Natural Language Programming.
•That simplicity exists because software engineers first built the models, cloud infrastructure, APIs, MCPs, databases, security, networking, data pipelines, RAG systems, and tooling that power these platforms.
•Companies like GitHub, Microsoft, Google, Amazon, Meta, OpenAI, and Anthropic build these foundations so others can create custom agents using natural language, often defined in markdown files.
•You can describe intent in natural language but building enterprise‑grade software still requires strong technical skills.
•Overall, programming has shifted from syntax-first to intent-first, lowering the barrier to building useful software and agents.
